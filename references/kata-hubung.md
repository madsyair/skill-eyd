# Kata Hubung (Konjungsi): Di Dalam Kalimat, Antarkalimat, dan Antarparagraf

Kesalahan konjungsi adalah kesalahan sintaksis yang paling sering ditemukan dalam karya ilmiah Indonesia. Akar masalahnya satu: penulis tidak membedakan **tingkat** yang dihubungkan. Baca file ini setiap kali menyunting teks yang panjangnya lebih dari satu paragraf atau ketika harness melaporkan kategori K-awal, T-koma, atau P-kepaduan.

## 1. Tiga tingkat konjungsi

| Tingkat | Menghubungkan | Posisi | Tanda baca | Contoh |
|---|---|---|---|---|
| **Intrakalimat** | kata↔kata, frasa↔frasa, klausa↔klausa dalam **satu** kalimat | di tengah kalimat (subordinatif boleh di awal jika anak kalimat mendahului induk) | koma sebelum *tetapi/sedangkan/melainkan*; koma setelah anak kalimat yang mendahului induk; **tanpa koma** sebelum *karena/sehingga/agar/jika/bahwa* di tengah kalimat | *Data dikumpulkan, tetapi belum diolah. Jika data lengkap, model dipasang.* |
| **Antarkalimat** | kalimat dengan kalimat **sebelumnya** dalam satu paragraf | **awal kalimat**, selalu diikuti koma | *Namun, / Oleh karena itu, / Selain itu,* | *Data telah dikumpulkan. Namun, pengolahannya belum selesai.* |
| **Antarparagraf** | gagasan paragraf dengan paragraf sebelumnya | kalimat pertama paragraf | bukan hanya konjungsi: kalimat transisi, pengulangan kata kunci, pengacuan | *Setelah data siap, tahap berikutnya adalah pemodelan.* |

Kaidah pokok: **konjungsi intrakalimat tidak mengawali kalimat baru; konjungsi antarkalimat tidak dipakai di tengah kalimat.**

## 2. Konjungsi intrakalimat

### 2a. Koordinatif (menghubungkan unsur setara)
| Makna | Konjungsi | Catatan |
|---|---|---|
| penambahan | *dan, serta* | *serta* untuk unsur terakhir setelah *dan* sudah dipakai, atau untuk gaya resmi |
| pemilihan | *atau, ataupun* | *dan/atau* boleh dalam teks hukum/teknis |
| pertentangan | *tetapi, melainkan, sedangkan, padahal* | didahului koma; *melainkan* setelah *bukan*; *tetapi* setelah *tidak* |
| penegasan | *bahkan, malah(an), lagi pula, apalagi* | |
| urutan | *lalu, kemudian* | didahului koma bila menghubungkan klausa |

### 2b. Subordinatif (menghubungkan induk dan anak kalimat)
| Makna | Konjungsi |
|---|---|
| waktu | *ketika, sewaktu, tatkala, saat, sementara, selagi, selama, seraya, sambil, sejak, semenjak, sebelum, sesudah, setelah, seusai, begitu, hingga, sampai* |
| syarat | *jika, jikalau, kalau, apabila, bila, asal(kan), manakala* |
| pengandaian | *andaikan, seandainya, sekiranya, umpamanya* |
| tujuan | *agar, supaya, untuk, guna, biar* (cakapan) |
| konsesif | *meskipun, walaupun, biarpun, kendatipun, sekalipun, sungguhpun* |
| pembandingan | *seperti, sebagaimana, seolah-olah, seakan-akan, laksana, ibarat, daripada, alih-alih* |
| sebab | *karena, sebab, oleh karena, oleh sebab* |
| akibat/hasil | *sehingga, sampai(-sampai), maka* (*maka* hanya bila anak kalimat syarat mendahului dan tidak ada konjungsi syarat lain; hindari *jika ..., maka* di luar teks matematis) |
| alat/cara | *dengan, tanpa, melalui* |
| komplementasi | *bahwa* (tanpa koma di depannya) |
| atributif | *yang* |
| perbandingan bertingkat | *semakin ... semakin, kian ... kian* |

### 2c. Korelatif (berpasangan; pasangannya tidak boleh ditukar)
| Benar | Salah yang sering muncul |
|---|---|
| *baik ... maupun ...* | *baik ... dan / baik ... ataupun / baik ... atau* |
| *tidak hanya ... tetapi juga ...* | *tidak hanya ... namun juga / tidak hanya ... melainkan juga* |
| *bukan hanya ... melainkan juga ...* | *bukan hanya ... tetapi juga* |
| *bukan ... melainkan ...* | *bukan ... tetapi* |
| *tidak ... tetapi ...* | *tidak ... melainkan* |
| *antara ... dan ...* | *antara ... dengan / antara ... atau* |
| *sedemikian rupa ... sehingga ...* | *sedemikian rupa ... hingga* (boleh), *sedemikian rupa ... agar* (salah) |
| *apa(kah) ... atau ...* | *apakah ... ataukah* (boleh, lebih tegas) |
| *entah ... entah ...* | *entah ... atau* |
| *jangankan ..., ... pun ...* | *jangankan ..., ... juga* |
| *demikian ... sehingga ...* | |
| *semakin ..., semakin ...* | *semakin ..., maka semakin* |
| *selain ..., ... juga ...* | *selain ..., ... pun* (boleh) |
| *tidak/bukan saja ..., tetapi/melainkan juga ...* | |

## 3. Konjungsi antarkalimat (awal kalimat + koma)

| Makna | Konjungsi | Padanan intrakalimat |
|---|---|---|
| pertentangan | *Namun, Akan tetapi, Meskipun demikian, Walaupun demikian, Kendati demikian, Sebaliknya, Di sisi lain, Padahal,* | *tetapi, sedangkan, melainkan, padahal* |
| akibat | *Oleh karena itu, Oleh sebab itu, Karena itu, Akibatnya, Sebagai akibatnya, Konsekuensinya,* | *sehingga, karena* |
| simpulan/konsekuensi lanjutan | *Dengan demikian, Jadi, Maka dari itu, Untuk itu,* | *sehingga* |
| penambahan | *Selain itu, Di samping itu, Lagi pula, Lebih lanjut, Lebih jauh, Bahkan, Tambahan pula, Demikian pula,* | *dan, serta, bahkan* |
| urutan/waktu | *Kemudian, Setelah itu, Sesudah itu, Selanjutnya, Sebelumnya, Sementara itu, Pertama, Kedua, Terakhir, Akhirnya,* | *lalu, kemudian, setelah, sementara* |
| penegasan/parafrasa | *Dengan kata lain, Artinya, Singkatnya, Intinya, Ringkasnya, Pada hakikatnya, Pada dasarnya, Sesungguhnya, Sebenarnya,* | — |
| contoh | *Misalnya, Sebagai contoh, Contohnya, Khususnya, Terutama,* | *seperti, misalnya* (dalam kalimat, didahului koma) |
| perbandingan | *Sama halnya, Serupa dengan itu, Sebanding dengan itu, Berbeda dengan itu,* | *seperti, sebagaimana* |
| pengalihan topik | *Adapun* (tanpa koma: *Adapun hasilnya ...*)*, Sehubungan dengan itu, Berkaitan dengan itu, Terkait hal itu, Dalam hal ini,* | — |
| pengecualian | *Kecuali itu,* | *kecuali* |

## 4. Pasangan yang paling sering tertukar

| Yang salah | Perbaikan | Alasan |
|---|---|---|
| *Tetapi ...* / *Tapi ...* di awal kalimat | *Namun, ...* / *Akan tetapi, ...* atau gabungkan: *..., tetapi ...* | *tetapi* intrakalimat |
| *..., namun ...* di tengah kalimat | *..., tetapi ...* | *namun* antarkalimat |
| *Namun demikian,* | *Namun,* atau *Meskipun demikian,* | *namun* sudah bermakna pertentangan; *demikian* mubazir (bentuk ini dipersoalkan Badan Bahasa) |
| *Sehingga ...* di awal kalimat | *Oleh karena itu,* / *Akibatnya,* / *Dengan demikian,* atau gabungkan | *sehingga* intrakalimat |
| *..., sehingga, ...* (koma setelah *sehingga*) | *... sehingga ...* | konjungsi intrakalimat tidak diikuti koma |
| *Sedangkan ...* di awal kalimat | *Sementara itu,* / *Sebaliknya,* / *Adapun ...* atau gabungkan: *..., sedangkan ...* | *sedangkan* intrakalimat |
| *Sementara ...* (maksud pertentangan) di awal kalimat | *Sementara itu, ...* (antarkalimat) atau *..., sedangkan ...* | *sementara* = konjungsi waktu ('selagi') |
| *Karena ...* tanpa induk kalimat | *Karena ..., ...* (tambah induk) atau *Oleh karena itu,* / *Sebab,* (cakapan) | anak kalimat tidak berdiri sendiri |
| *Dan ...* / *Atau ...* / *Serta ...* di awal kalimat | *Selain itu,* / gabungkan | koordinatif intrakalimat (dalam ragam sastra/populer boleh) |
| *Dimana ...* / *Yang mana ...* di awal kalimat | ubah struktur; gunakan *Hal ini*, *Dalam hal ini*, atau gabungkan dengan *yang* | bukan konjungsi bahasa Indonesia (kalke *where/which*) |
| *Yang ...* di awal kalimat sebagai penyambung | gabungkan dengan kalimat sebelumnya atau ulang nomina | *yang* atributif intrakalimat |
| *Jika ..., maka ...* / *Karena ..., maka ...* / *Meskipun ..., tetapi ...* / *Setelah ..., kemudian ...* | hapus salah satu | konjungsi ganda dalam satu hubungan |
| *Dengan demikian,* untuk menyatakan akibat langsung | *Oleh karena itu,* | *dengan demikian* = simpulan/konsekuensi lanjutan; *oleh karena itu* = akibat |
| *Oleh karena itu,* untuk menutup penalaran (simpulan) | *Dengan demikian,* / *Jadi,* | (kebalikannya) |
| *Selain daripada itu,* | *Selain itu,* | *daripada* hanya untuk perbandingan |
| *Disamping itu,* | *Di samping itu,* | *di* kata depan |
| *Sebab ...* di awal kalimat resmi | *Karena ..., ...* atau *Sebabnya, ...* / *Alasannya, ...* | *sebab* di awal kalimat ragam cakapan |
| *Namun* / *Oleh karena itu* tanpa koma | tambahkan koma | konjungsi antarkalimat selalu diikuti koma |
| *Adalah karena ...* (*Penyebabnya adalah karena ...*) | *Penyebabnya adalah ...* / *Hal ini terjadi karena ...* | *adalah* + *karena* rancu |
| *dikarenakan* | *karena* / *disebabkan oleh* | tidak baku |
| *disebabkan karena* | *disebabkan oleh* / *karena* | pleonasme |
| *walau begitu/pun* | boleh (populer); resmi: *walaupun demikian* | ragam |
| *kendati* ✓, *kendatipun* ✓, *kendati demikian* ✓ | | |
| *sementara* + *itu* di tengah kalimat (*..., sementara itu ...*) | *..., sementara ...* / *..., sedangkan ...* | *sementara itu* antarkalimat |
| *Bahkan* di awal kalimat tanpa koma | *Bahkan, ...* | antarkalimat |
| *dan lain sebagainya* | *dan sebagainya* / *dan lain-lain* | pleonasme |
| *guna untuk* | *untuk* / *guna* | pleonasme |
| *agar supaya* | *agar* / *supaya* | pleonasme |
| *maka* setelah *dengan demikian / oleh karena itu* (*Oleh karena itu, maka ...*) | hapus *maka* | ganda |

## 5. Konjungsi antarparagraf: jangan hanya mengandalkan konjungsi

Kalimat pembuka paragraf memikul dua tugas: menyatakan gagasan paragraf **dan** mengaitkannya dengan paragraf sebelumnya. Konjungsi antarkalimat (*Selain itu, Namun,*) di awal paragraf sah, tetapi lemah karena pembaca harus mengingat kalimat terakhir paragraf sebelumnya. Urutan preferensi:
1. **Kalimat transisi bermuatan isi**: *Kelemahan model di atas dapat diatasi dengan ...* / *Setelah prior ditentukan, langkah berikutnya adalah ...* / *Temuan ini berbeda dengan hasil Susenas 2023 yang ...*
2. **Pengulangan kata kunci** paragraf sebelumnya di posisi subjek: *... menghasilkan **estimasi tingkat kecamatan**. → **Estimasi tingkat kecamatan** itu selanjutnya divalidasi ...*
3. **Pengacuan ringkas** + nomina: *Ketiga keterbatasan tersebut ..., Pola serupa ..., Pendekatan kedua ...*
4. **Penanda struktur** yang diumumkan sebelumnya: *Faktor kedua adalah ...* (setelah *Ada tiga faktor ...*).
5. **Konjungsi antarkalimat** sebagai pilihan terakhir, dan jangan dua paragraf berturut-turut dengan konjungsi yang sama.
Hindari membuka paragraf dengan *Dan, Sehingga, Sedangkan, Dimana, Yang mana, Tetapi, Sementara* (tanpa *itu*).

## 6. Daftar periksa konjungsi (dipakai dalam loop)
- [ ] Tidak ada kalimat yang diawali *Sehingga, Sedangkan, Tetapi/Tapi, Dan, Atau, Dimana, Yang mana, Yang, Sementara* (tanpa *itu*).
- [ ] Tidak ada *namun / akan tetapi / oleh karena itu / selain itu* di tengah kalimat.
- [ ] Setiap konjungsi antarkalimat di awal kalimat diikuti koma (kecuali *Adapun*; dan ingat *Pertama/Ketiga/Akibatnya* bisa juga numeralia atau subjek: *Ketiga faktor itu*, *Akibatnya tajam* — di situ koma justru salah).
- [ ] Tidak ada konjungsi ganda (*meskipun–tetapi, karena–maka, jika–maka* nonmatematis, *setelah–kemudian*).
- [ ] Pasangan korelatif lengkap dan benar (*baik–maupun, tidak hanya–tetapi juga, bukan–melainkan, antara–dan*).
- [ ] *Dengan demikian* untuk simpulan; *oleh karena itu* untuk akibat.
- [ ] *Sedangkan* untuk pertentangan; *sementara* untuk waktu; *sementara itu* untuk antarkalimat.
- [ ] Anak kalimat selalu punya induk; *karena/jika/meskipun* di awal kalimat diikuti koma dan induk.
- [ ] Paragraf tidak dibuka dengan konjungsi yang sama dua kali berturut-turut; lebih baik kalimat transisi bermuatan isi.
