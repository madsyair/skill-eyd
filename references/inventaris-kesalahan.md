# Inventaris Kesalahan Penulisan Bahasa Indonesia

Daftar ini adalah "peta ranjau": pola kesalahan yang paling sering muncul dalam tulisan ilmiah, laporan resmi, dokumen instansi, dan artikel populer. Setiap butir memberi bentuk salah → bentuk benar dan alasan singkatnya. Gunakan bersama `scripts/periksa.py` (yang mendeteksi sebagian besar pola di sini secara otomatis) dan `kalimat-efektif.md` (untuk kesalahan pada tingkat kalimat dan paragraf).

Kode kategori dipakai dalam laporan penyuntingan: **E** ejaan/kata baku, **I** imbuhan, **D** kata depan/bentuk terikat, **G** gabungan kata, **P** partikel, **S** singkatan/angka, **T** tanda baca, **K** kalimat (struktur), **M** kemubaziran/pleonasme, **L** logika/kecermatan makna, **R** ragam (cakapan vs tulis), **A** istilah asing/KBBI.

## T. Tanda baca

T1. Koma sebelum *tetapi/sedangkan/melainkan*: *Data lengkap tetapi tidak valid* → **..., tetapi ...**
T2. Koma setelah anak kalimat di depan: *Jika hujan turun acara dibatalkan* → **Jika hujan turun, acara dibatalkan.**
T3. Tidak ada koma jika induk di depan: *Acara dibatalkan, jika hujan turun* → **Acara dibatalkan jika hujan turun.**
T4. Koma setelah penghubung antarkalimat: *Oleh karena itu penelitian ini* → **Oleh karena itu, penelitian ini** (juga *Namun, / Selain itu, / Dengan demikian, / Jadi, / Sebaliknya, / Akan tetapi, / Sementara itu, / Pertama, / Kedua, / Di sisi lain, / Meskipun demikian, / Sehubungan dengan itu,*).
T5. Tidak ada koma sebelum *bahwa*: *menunjukkan, bahwa* → **menunjukkan bahwa**.
T6. Tidak ada koma antara subjek panjang dan predikat: *Hasil estimasi model regresi logistik, menunjukkan* → **... menunjukkan**.
T7. Koma pada perincian termasuk sebelum *dan* terakhir (≥3 unsur): *A, B dan C* → **A, B, dan C**.
T8. Koma sebelum *yaitu/yakni/misalnya/antara lain/seperti* (perincian): *tiga peubah yaitu* → **tiga peubah, yaitu**.
T9. Tidak ada titik dua setelah *adalah/yaitu/meliputi/terdiri atas*: *terdiri atas: A, B* → **terdiri atas A, B, ...**; titik dua hanya setelah pernyataan lengkap: *Ada tiga peubah: A, B, dan C.*
T10. Titik koma untuk perincian yang mengandung koma / berupa klausa.
T11. Tanda hubung vs tanda pisah: rentang pakai tanda pisah (*2020—2024*), bukan hubung.
T12. Spasi: tidak ada spasi sebelum , . ; : ? ! ; ada satu spasi sesudahnya. Tidak ada spasi setelah kurung buka/sebelum kurung tutup. Tidak ada spasi ganda.
T13. Tanda baca akhir pada petikan langsung di dalam tanda petik: *"Saya setuju," ujarnya.* Titik/koma **di dalam** petik untuk petikan langsung.
T14. Titik tidak dipakai di akhir judul, judul tabel/gambar, dan item daftar berupa frasa (konsistenkan: semua item frasa tanpa titik, atau semua kalimat dengan titik).
T15. *et al.* dimiringkan dan diberi titik; *dkk.* diberi titik.
T16. Kurung: kepanjangan lalu singkatan pada penyebutan pertama: **Badan Pusat Statistik (BPS)**, selanjutnya *BPS* saja.
T17. Tanda tanya/seru tidak digandakan (*?!*, *!!!*) dalam ragam resmi.
T18. Petik tunggal untuk makna: *disebut "overfitting" 'terlalu pas'* → gunakan kurung untuk padanan istilah: ***overfitting* (kelewat pas)** dan petik tunggal untuk makna kata.

## K. Struktur kalimat (kesepadanan)

K1. **Subjek berkata depan** (subjek hilang): *Dalam penelitian ini membahas ...* → **Penelitian ini membahas ...** · *Berdasarkan hasil analisis menunjukkan bahwa* → **Hasil analisis menunjukkan bahwa** · *Menurut Alwi (2010) mengatakan bahwa* → **Menurut Alwi (2010), ...** atau **Alwi (2010) mengatakan bahwa** · *Dari data tersebut dapat diketahui ...* (boleh: subjek "bahwa ..."; lebih baik **Data tersebut menunjukkan ...**) · *Pada tabel 3 menunjukkan* → **Tabel 3 menunjukkan** · *Bagi mahasiswa yang terlambat tidak diperkenankan masuk* → **Mahasiswa yang terlambat tidak diperkenankan masuk** · *Untuk pengumpulan data dilakukan dengan* → **Pengumpulan data dilakukan dengan**.
K2. **Konjungsi ganda**: *Meskipun ..., tetapi/namun ...* → hapus salah satu · *Karena ..., maka ...* → hapus *maka* · *Walaupun ..., akan tetapi* → hapus satu · *Setelah ..., kemudian* → hapus *kemudian* · *Jika ..., maka* → hapus *maka* (dalam teks matematis *maka* boleh dipertahankan sebagai konvensi "jika–maka") · *Berdasarkan ..., maka* → hapus *maka* · *Agar ..., maka* → hapus *maka*.
K3. **Kalimat diawali konjungsi intrakalimat**: *Sehingga ..., Sedangkan ..., Tetapi ..., Karena ... (tanpa induk)* → gabungkan dengan kalimat sebelumnya atau ganti dengan penghubung antarkalimat: *Sehingga* → **Dengan demikian, / Akibatnya, / Oleh karena itu,** · *Sedangkan* → **Sementara itu, / Sebaliknya, / Adapun** · *Tetapi/Tapi* → **Namun, / Akan tetapi,** · *Karena* di awal boleh **hanya** jika ada induk kalimat sesudahnya (*Karena hujan, acara dibatalkan.*).
K4. **Anak kalimat tanpa induk** (kalimat buntung): *Karena data yang digunakan bersifat sekunder.* → gabungkan.
K5. **Predikat hilang** karena *yang*: *Mahasiswa yang mengikuti ujian.* → **Mahasiswa mengikuti ujian.** / **Mahasiswa yang mengikuti ujian wajib membawa KTM.**
K6. **Keparalelan**: unsur sejajar harus sekelas kata: *tahap pengumpulan data, mengolah data, dan analisis* → **pengumpulan, pengolahan, dan analisis data** · *bertujuan untuk mengukur ... dan penentuan ...* → **mengukur ... dan menentukan ...**.
K7. **Subjek ganda/berulang**: *Penelitian ini, penelitian ini bertujuan* → hapus pengulangan; *Ia dia* ✗.
K8. **Pasif–aktif bercampur** dalam satu kalimat majemuk: *Peneliti mengumpulkan data, kemudian dianalisis dengan regresi* → **Peneliti mengumpulkan data, kemudian menganalisisnya dengan regresi** / **Data dikumpulkan, kemudian dianalisis ...**.
K9. **"yang mana" / "di mana" / "dimana" sebagai penghubung relatif** (kalke dari *which/where*): *metode yang mana digunakan* → **metode yang digunakan**; *daerah dimana kemiskinan tinggi* → **daerah dengan tingkat kemiskinan tinggi / daerah yang kemiskinannya tinggi**. *Di mana* hanya untuk pertanyaan tempat atau kalimat yang menyatakan tempat secara harfiah (*di mana ia tinggal*).
K9a. **Konjungsi salah tingkat** (rinci di `kata-hubung.md`): *..., namun ...* → **..., tetapi ...**; *Tetapi ...* di awal → **Namun, ...**; *Namun demikian,* → **Namun, / Meskipun demikian,**; *Sementara ...* (pertentangan) di awal → **Sementara itu, ... / ..., sedangkan ...**; *..., sehingga, ...* → **... sehingga ...** (tanpa koma); *Selain daripada itu* → **Selain itu**; *Dan/Atau/Serta ...* di awal kalimat → gabungkan.
K9b. **Korelatif salah pasang**: *tidak hanya ... namun/melainkan juga* → **tidak hanya ... tetapi juga**; *bukan hanya ... tetapi juga* → **bukan hanya ... melainkan juga**; *baik ... dan/atau* → **baik ... maupun**; *antara ... atau* → **antara ... dan**; *semakin ..., maka semakin* → **semakin ..., semakin**.
K9c. **Dengan demikian vs oleh karena itu**: *oleh karena itu* menyatakan akibat; *dengan demikian* menyatakan simpulan/konsekuensi lanjutan. *Oleh karena itu, maka* → hapus *maka*.
K9d. **Kata tunjuk tanpa acuan**: *Hal ini* / *tersebut* di awal paragraf yang tidak menunjuk sesuatu yang jelas → ganti nomina eksplisit.
K9e. **Elipsis subjek lintas kalimat**: *... Kemudian diuji pada data uji.* → **Kemudian, model diuji ...**
K10. **Kalimat terlalu panjang** (>35–40 kata atau >3 klausa): pecah. Satu kalimat, satu gagasan.
K11. **"adanya", "akan", "daripada", "dari" mubazir sebagai penanda objek/topik**: *Hal ini menyebabkan adanya penurunan* → **Hal ini menyebabkan penurunan** · *Kami menganalisis akan pengaruh* → hapus *akan* · *Dari hasil penelitian menunjukkan* → **Hasil penelitian menunjukkan** · *hasil daripada analisis* → **hasil analisis** (*daripada* hanya untuk perbandingan).
K12. **Pengubahan nomina berkata "dari"** (kalke *of*): *pengaruh dari inflasi* → **pengaruh inflasi**; *ketua dari panitia* → **ketua panitia**.

## L. Logika, kecermatan makna, dan pilihan kata

L1. **Preposisi berpasangan yang salah**: *antara ... dengan* → **antara ... dan** · *terdiri dari* → **terdiri atas** · *tergantung pada* → **bergantung pada** (*tergantung* = digantung) · *berbeda dari/dengan* ✓ keduanya · *sesuai dengan* ✓ (bukan *sesuai* + nomina langsung dalam ragam resmi) · *bertemu dengan* ✓ · *terbuat dari* ✓ · *dibandingkan dengan* ✓ (bukan *dibandingkan* + nomina langsung; *dibanding* + nomina juga diterima) · *berhubungan dengan* ✓ · *tidak ... melainkan* → **bukan ... melainkan**; **tidak ... tetapi** · *baik ... ataupun* → **baik ... maupun** · *entah ... entah* ✓ · *bukan hanya ... tetapi juga* ✓ · *tidak hanya ... tetapi juga* ✓ · *jangankan ..., ... pun* ✓.
L2. **Pilihan kata yang tertukar**: *jam* (durasi) vs **pukul** (waktu) · *sesuatu* (tak tentu, berdiri sendiri) vs **suatu** (diikuti nomina): *suatu metode* ✓, *sesuatu hal* ✗ → **suatu hal / sesuatu** · *masing-masing* (tanpa nomina di belakang; mengacu ke yang sudah disebut) vs **tiap-tiap/setiap** (diikuti nomina): *masing-masing daerah* → **setiap daerah / daerah masing-masing** · *seluruh* (satu kesatuan utuh: seluruh Indonesia) vs **semua** (jumlah: semua responden) · *beberapa* vs *sebagian* · *acuh* (peduli) → *tidak acuh* jika maksudnya abai; hindari *acuh* untuk 'abai' · *absen* (tidak hadir) vs *hadir*; *mengisi daftar hadir* bukan *mengisi absen* · *bergeming* (diam) — *tidak bergeming* berarti bergerak; hati-hati · *nuansa* (variasi halus), bukan 'suasana' · *sekali-kali* (sesekali) vs *sekali-sekali* · *kilah* (dalih) — *berkilah* bukan 'menjelaskan' · *canggih* ✓ · *efektif* (tepat guna) vs *efisien* (hemat) · *metode* (cara sistematis) vs *metodologi* (ilmu tentang metode): *metodologi penelitian* untuk bab, *metode* untuk tekniknya · *peubah/variabel* konsisten satu istilah · *data* (jamak, dalam BI tunggal-jamak sama) → *data ini* ✓ · *responden* vs *sampel* vs *unit analisis* — cermat · *signifikan* (statistik) vs *bermakna/berarti* (umum) · *presentase* → **persentase**; *persen* dengan angka: *5 persen / 5%* · *lebih dari* (bukan *lebih daripada* untuk angka: *lebih dari 100*) · *di antara* untuk pilihan/kelompok, *antara* untuk rentang: *antara 2020 dan 2024* · *pada* (waktu/abstrak) vs *di* (tempat): *pada tahun 2026, pada tabel 3, di Jakarta*; *di tahun 2026* (populer) → **pada tahun 2026** (resmi) · *ke depan* (waktu) ✓ · *dalam rangka* → sering mubazir; **untuk** · *terkait* sebagai kata depan (*terkait masalah itu*) → **terkait dengan / mengenai / tentang** · *seputar* (cakapan) → **mengenai / tentang** · *guna* (resmi, boleh) · *bilamana* (kapan) vs *jika* · *apabila/jika/kalau* — *kalau* ragam cakapan · *seringkali* → **sering kali** · *kadangkala* → **kadang kala** / **kadang-kadang**.
L3. **Kata ganti dan sapaan dalam ragam ilmiah**: *kami/kita* — *kita* melibatkan pembaca; *penulis/peneliti* untuk tulisan ilmiah; *saya* untuk esai/opini; *Anda* (kapital) untuk pembaca dalam petunjuk; hindari *kamu/kalian/lo/gue* · *beliau* untuk orang yang dihormati; *ia/dia* untuk orang ketiga; *ia* lebih formal, tidak dipakai sebagai objek (*menemuinya*, bukan *menemui ia*) · *mereka* tidak untuk benda; *peubah-peubah tersebut*, bukan *mereka*.
L4. **Ambiguitas**: *Istri dosen yang ramah itu* → *Istri dosen-yang-ramah itu* / *istri-dosen yang ramah itu*; gunakan tanda hubung atau ubah susunan. *Pengaruh pendidikan ibu dan ayah terhadap gizi anak* — apakah "pendidikan ayah" atau "ayah" saja? Perjelas: *pendidikan ibu dan pendidikan ayah*.
L5. **Logika kalimat**: *Waktu dan tempat kami persilakan* → **Bapak X kami persilakan** · *Untuk mempersingkat waktu* → **Untuk menghemat waktu** · *Kepada Bapak Rektor, waktu dan tempat dipersilakan* → **Bapak Rektor kami persilakan** · *Berhubung keterbatasan waktu* → **Karena waktu terbatas** · *Hasil penelitian menyimpulkan* → **Penelitian ini menyimpulkan / Hasil penelitian menunjukkan** (hasil tidak menyimpulkan) · *Penelitian ini bertujuan untuk mengetahui* → **bertujuan mengetahui / menganalisis** · *Data bersumber dari BPS dan literatur* → **data BPS dan kepustakaan**.

## R. Ragam (cakapan vs tulis resmi)

Hindari dalam tulisan resmi/ilmiah: *tapi → tetapi; nggak/gak/enggak → tidak; kayak → seperti; banget → sangat/sekali; bilang → mengatakan; gimana → bagaimana; gitu/gini → begitu/begini; udah → sudah; aja → saja; emang → memang; doang → saja/hanya; cuma ✓ (baku, tetapi ragam santai → hanya); kalo → kalau/jika; ntar → nanti; sih, dong, deh, kok, lho, nih → hapus; ngomong → berbicara; ngasih → memberi; nyari → mencari; bikin → membuat; dapet → mendapat; jadi (awal kalimat cakapan) → Jadi, (boleh sebagai penghubung antarkalimat resmi); punya → mempunyai/memiliki; ketemu → bertemu; ngerti → mengerti; ok/oke → baik; sama (=dengan) → dengan; buat (=untuk) → untuk; kasih → memberi; kayaknya → tampaknya; makanya → oleh karena itu; soalnya → karena; yang namanya → hapus; pokoknya → intinya/singkatnya; dimana-mana → di mana-mana; ngga ada → tidak ada; ga usah → tidak perlu; tau → tahu; kan → hapus/bukan; ntar → nanti; entar; trus → lalu/kemudian; tapinya → tetapi; pake → memakai/menggunakan; nanya → bertanya; ngapain → mengapa/untuk apa.*
Ragam populer (blog, media sosial, buku populer) boleh lebih luwes (*tapi, oke, cuma*), tetapi ejaan dan struktur kalimat tetap benar.

## A. Istilah asing dan padanan KBBI (lihat `istilah-dan-kbbi.md`)

Kesalahan yang sering: (1) istilah asing tidak dimiringkan; (2) padanan KBBI dipaksakan padahal belum populer sehingga pembaca tidak paham; (3) istilah asing dipakai padahal padanan Indonesia sudah umum; (4) tidak konsisten (satu tulisan memakai *dataset* dan *gugus data* bergantian); (5) singkatan asing tidak diperkenalkan; (6) bentuk hibrida yang tidak baku (*di-upload* boleh, tetapi *diupload* ✗; *mengupload* ✗ → *mengunggah*).
